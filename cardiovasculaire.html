❤️ Système cardiovasculaire

Définition

Le système cardiovasculaire est constitué du cœur et des vaisseaux sanguins. Il assure la circulation du sang dans tout l'organisme.

❤️ Le cœur

Le cœur est un organe musculaire qui fonctionne comme une pompe. Il propulse le sang vers les poumons et les différents organes du corps.

🩸 Les vaisseaux sanguins

Les principaux vaisseaux sanguins sont les artères, les veines et les capillaires.

Artères

Elles transportent généralement le sang du cœur vers les organes.

Veines

Elles ramènent généralement le sang des organes vers le cœur.

Capillaires

Ils permettent les échanges entre le sang et les tissus.

📌 À retenir

Le cœur pompe le sang, les artères l'acheminent vers les tissus, les veines le ramènent vers le cœur et les capillaires permettent les échanges avec les tissus.
